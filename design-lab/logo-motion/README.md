# ルナルーチェ ロゴの動き（2026-11-24 決定版）

- 決定版: index.html （ブラウザで開くと動く）
- 公開ページ: https://claude.ai/artifact/2a4grh8JSFqiUjLANvgeLB （Version 7）
- 作り方: head.html（見た目と説明）＋ anim.js（動き。`__B64__` を nodiamond.b64 の中身に置き換える）を1つにまとめたもの。
- nodiamond.png = 今のロゴ静止画から真ん中のひし形を消したもの（ひし形は動きの中で描く）。
- 旧版の動きはプロジェクトのファイル logo-motion/ に保存

流れ（約23秒）: ひし形⇄ハートの鼓動が4回で大きくなり、ロゴより大きくなって弾ける → ピンクの粒がふわっと戻ってハート → くっきりしたハート → 少しずつ満月（クレーター3つ） → 背景が抜ける形で三日月 → 流星が止まらずに飛んできて2周し、らせんで三日月に当たる → 画面全体に均等に散る → 星が奥と手前に楕円で回りながら大きくなり、ロゴが現れる → 星が集まってひし形。
