## 3. 見本の共通の作り（本実装でそろえる）

各見本は同じ形です。

- `page.json` … ページ情報（`page.kind: "special"`、slug、タイトル、パンくず）と `blocks` の配列。**並び順＝ページの並び順**。サイトビルダーで保存される中身の例。
- `blocks/<部品名>.cjs` … 部品1つ＝1ファイル。JSONの1ブロックを受け取りHTMLを返す。
- `<名前>.css` … そのページの部品の見た目。色は今のサイトの変数（`--teal` `--teal-d` `--coral-d` `--sub` など）を使う。
- `build.cjs` … 外枠（ヘッダー・フッター）を今のページから借りて preview を書き出す。登録されていない部品・無い写真があれば止まる。

**本実装でやってほしいこと：** 4つの見本で `hero` `flow` `faq` `notes` `contact` `form` などが別々に書かれて重複しているので、**特別ページ共通の部品集**（例 `site-src/special-blocks/`）に1つにまとめ、テーマの変数で色が変わるようにする。新しいテーマを入れるときに、この部品集もテーマに従うようにする。`page.kind: "special"` のページを build-site が生成できるようにし、`pages.json`／部品台帳（component-registry）に登録する。

## 4. それぞれの中身と林さんの決定

### 4-1. 大口注文（見積もりページ）`samples/bulk-lp/page.json`
- 部品：hero → switch（見積もり／大口セットの切り替え）→ ways（選び方3つ）→ scenes（使う場面）→ benefits（特典）→ services（企業・式場向け4サービス）→ plans（予算別、**金額は仮**）→ router（合計の目安計算）→ flow → form → contact → faq
- 林さんの決定：
  - **個数より金額が大事。** 同じ商品300個以上、**または** 1つの商品で10万円以上なら、個数に関係なくお見積もり（特別価格）。
  - 受付は**OMS**で受ける。フォームはかんたん（名前・メール・電話・使う日・だいたいの個数・だいたいの予算）＋気軽に書ける相談欄（書き出しボタン付き）。
  - 300個未満の人向けの「大口セット商品」は残す。ページは「見積もり」と「大口セット」に**分ける**（入口で振り分け）。
  - 実際の納品写真は無い。商品写真から作った絵（`img/zurari.jpg` ずらり並んだ箱・`catalog.jpg`・`sample.jpg`、作り方 `tools/make-images.py`）を使う。「ずらり」は林さん「悪くない」。
  - 合計の目安計算はOK。
  - 特典・企業向けサービス（後納＝出荷当月末払い、サンプル請求チケット、カタログ同梱、小袋・紙袋サービス）は本店の大口ページに書いてある内容そのまま。
- 未決：プランの金額と中身。大口セット商品が今あるか（本店ページには見出しだけで商品が並んでいない。林さんが担当者に確認中）。

### 4-2. 大口セット商品ページ `samples/bulk-lp/page-set.json`

### 4-3. デジタルカタログ `samples/bulk-lp/catalog/`
- 林さんの要望：ページをめくれる。お客さまが印刷（PDF）もできる。HP上で写真を押すと、**大口の条件のまま**注文・相談に入れられる。**カタログはOMSで作れる**ようにする。スマホでも使えること。
- 見本の動き：スマホは1ページ、PCは見開き。スワイプ／前へ・次へでめくる。商品を押すと個数欄（50・100・300個ボタン付き）と合計の目安、300個以上か10万円以上で「特別価格でお見積もり」に切り替わる。「相談リストに入れる」で右上のリストに貯まる。印刷ボタン（本番で付ける）。
- データは `catalog.json`（表紙・条件 `bulk.limit/qty`・pages[].items[]）。**価格・商品は仮**。本番では商品データ（OMS）から引く。
- OMS側の画面見本は `oms-mock-bulk.html` の「カタログ：デジタルカタログを作る」。相談リストの送り先はOMSの「大口のご相談」。

## 5. テーマの実装と一緒に入れるときの順番（おすすめ）

1. 上のブランチを取り込み、`samples/` の見本を5幅で開いて中身を把握する。
2. 特別ページ共通の部品集を作り、4つの見本の重複部品を1つにまとめる（テーマの色変数に従わせる）。
3. `page.kind: "special"` を build-site で生成できるようにし、大口（見積もり・大口セット）・提携の3ページを `site-src` 側に置く（見本の page.json をそのまま使える形）。
4. トップの入口①〜④を部品として追加（置く・外すを設定で選べる形）。
5. デジタルカタログのビューアを部品化（catalog.json を読む）。OMS側の作成画面・大口セット企画は、OMSの今の本番には入れず、この試作リポジトリの中で画面を作る。
6. 5幅確認・`--check`・CI。林さんに画像で確認をもらってから次へ。
