# store-design-switcher

お店のサイトを「お店の中身」「デザイン（テーマ）」「季節・企画」の3つに分け、
OMS（管理画面）のボタンでデザインと季節を切り替えられるようにする仕組みの**試作用リポジトリ**です。

- 出発点：`Ghodam5/lunaluce-sample` の main（v75、コミット d79cba5、2026-11-24）をそのまま写したもの。履歴は持ってきていません。
- 設計書：「OMSとHPの汎用化設計（デザイン切り替えの仕組み）」 https://claude.ai/artifact/2uJY7oZr49xcHMWUCKbyGy
- 見本URL（GitHub Pages）：https://ghodam5.github.io/store-design-switcher/top.html

## 必ず守ること（2026-11-24 林さん決定）

- **今のサイト `Ghodam5/lunaluce-sample` と、VPSで動いている今のOMSは一切変更しない。** ここでの作業をそちらへ反映・push・PRしない。
- 林さんが合格を出すまで、本番サイト・本番Welcart・今のOMSにはつながない。
- 将来は他のお店にも貸せる形にするので、ルナルーチェ固有の情報はデザインに埋め込まない。

## 進め方（設計書の順番）

1. 色の直書きをなくす（見た目は変えない）
2. 形と見た目のCSSを分ける（今の見た目を「テーマ：いつもの」にする）
3. お店の情報を共通部品から出す
4. テーマ・季節の入れ物と自動テスト、演出の部品、商品の自動切り抜き
5. 決まったデザインをテーマとして作る
6. 試し用の「デザイン」画面（OMS風）
7. 企画の期間と季節をつなぐ
8. お店ごとに分ける
